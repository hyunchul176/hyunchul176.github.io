# News Images

Drop news photos here using the **exact filenames** below. Any file that
doesn't exist is automatically hidden in the page (no broken image icon).

Recommended size: **1200 × 750 px** (16:10), JPG, < 300 KB each.
Smaller is fine — the CSS scales them.

## How to get images from your Google Sites

1. Open https://sites.google.com/view/hyunchul17/news
2. Right-click on each image → **Save image as...**
3. Rename the file to match the list above
4. Drop it into this `assets/news/` folder
5. Refresh the page locally

Don't have the original photos? Just leave them out — the page will look
fine without them.
