# Publication thumbnails

Drop figure thumbnails here using these filenames. Missing files
auto-fall back to a label (e.g. "TRF 2025"), so you can add them
later without breaking anything.

Recommended size: **400 × 280 px** (thumbnail used at 140 × 100).

- `trf-2025.jpg` — Drivers Overtaking Bicycles & E-Scooters (TRF, 2025)
- `aap-2024.jpg` — Pedestrian Scale Warning System (AAP, 2024)
- `tust-2025.jpg` — Information Delivery in Tunnels (TUST, 2025)
- `subway-fire.jpg` — Subway fire evacuation (under review)

Tip: a small representative figure from the paper (e.g. the experimental
setup) works best.
